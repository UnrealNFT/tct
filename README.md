# TCT 🔥

**The Next Viral Thing**

Une app de duels viraux : crée des "Would you rather" déjantés, fais voter tes potes, monte au classement et partage ton résultat.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## Lancer en local

```bash
npm install
npm run dev
```

## Pourquoi ça peut devenir viral

- Création de duel en 10 secondes
- Vote anonyme et instantané
- Compte à rebours 24h qui crée l'urgence
- Partage natif avec image de résultat
- Leaderboard mondial
- Mode sombre TikTok-friendly
